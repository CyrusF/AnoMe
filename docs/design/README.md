# 设计与验收记录

基准是用户确认的第二版单栏设计：[前台](public-reference.png)、[管理页](admin-reference.png)。2026-11-02 的后续反馈覆盖推荐区的原样式：去掉左侧装饰线，改成无边框浅蓝圆角区域，同时用间距区分底部操作。推荐功能及文案保留。

## 页面验证

使用 Codex 内置浏览器，在本地真实 Worker、D1 和 DeepSeek 上验证了提问、待回复追踪、登录、发布、编辑、相似推荐、同问／取消、收藏／刷新、独立链接、复制链接和限额设置。桌面与 390px 手机宽度都已检查；前台和管理页没有横向溢出。页面无空白、构建错误遮罩或相关控制台错误。

生产检查确认首页、健康接口、公开列表、真实 DeepSeek 预检查和管理员登录均正常，公开列表与收件箱为空。请求编号可关联到 Cloudflare 中的数据库、模型耗时／用量、审核和最终响应日志。

## 设计对照

| 检查项     | 结果                                                               |
| ---------- | ------------------------------------------------------------------ |
| 布局       | 居中单栏，最大阅读宽度 880px；管理问题在原位展开，手机保持相同顺序 |
| 色彩       | 冷灰蓝底、白色表面、暗红主操作、少量冷咖色强调                     |
| 圆角       | 主卡片 24px、输入框 18px、推荐区 20px、胶囊操作按钮                |
| 字体       | 调大桌面主标题、问题及操作文字，区分正文、提示与时间信息           |
| 推荐区     | 按用户最后反馈取消装饰竖线和底部分隔线，缩短不必要的高度           |
| 文案       | 主标题、导航、提交及推荐操作文案与确认稿一致；无额外营销区块       |
| 图标与交互 | 同问、收藏、链接为一致的细线图标；手机管理图标保留可读标签         |
| 响应式     | 390px 下推荐及操作自然换行，前台、管理页均无横向溢出               |

在同一轮验收中使用 `view_image` 检查了确认稿与实际截图。桌面检查的 CSS 视口为前台约 1016×1548、管理页约 1036×1518。内置浏览器当前缩放使导出的 JPEG 尺寸为 CSS 视口的 1.25 倍，因此通过 DOM 尺寸和图片直接对照共同检查；没有把截图当作实际界面使用。

有意保留的差别：使用系统中文字体、真实时间／同问数，生产没有示例数据；推荐区按用户最新反馈更新。测试问答仅存在于本地。未发现需要保留的功能或布局缺陷。

## 有界验证

18 项 Workers 接口测试通过。真实 DeepSeek 另外确认普通批评通过、明确推广广告被拒绝，并能返回已有公开问答的相似链接。

SQL 状态穷举使用 Python 3.13.0 与 SQLite 3.45.3，检查 326 个状态、2581 次转换，并抓到了三种故意破坏的生产 SQL。覆盖范围及重新验证方法见项目内的 `verify-submission-state` 技能。
